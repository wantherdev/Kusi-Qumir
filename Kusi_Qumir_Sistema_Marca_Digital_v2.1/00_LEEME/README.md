# Kusi Q’umir - Sistema de Marca Digital 2.1

Este paquete sustituye los manuales y kits anteriores para todas las operaciones digitales de la marca.

## Base canónica

- Logotipo e isotipo: geometría aprobada v1.3.
- K / Río Andino: `#9BBFE6`.
- Sol y Q: `#00ABAA`.
- Montañas: `#647BAB`.
- Nombre y fondo oscuro: `#0F172A`.
- Titulares: Fjalla One 400.
- Interfaz y lectura: Inter 400, 500, 600 y 700.

## Alcance actual

Incluye reglas para web, redes sociales, publicidad digital, perfiles, WhatsApp Business, correo, plataformas de reserva y recursos descargables. Todo debe exportarse en sRGB.

No define CMYK, impresión, bordado, uniformes ni señalética. Esos soportes requieren un anexo de producción cuando la marca empiece a operar físicamente.

## Orden de uso

1. Leer el manual PDF en `02_Manual`.
2. Usar los SVG como maestros para web y escala.
3. Usar PNG cuando la plataforma no admita SVG.
4. Instalar las fuentes de `03_Tipografias` antes de editar el PPTX.
5. Implementar los tokens de `04_Tokens_Desarrollo` sin introducir variantes heredadas ni aproximaciones cromáticas.

## Favicon e iconos instalables

- El favicon del navegador (`SVG`, `PNG` e `ICO`) usa fondo transparente y los colores canónicos del isotipo.
- Los iconos PWA y Apple Touch conservan fondo slate para resistir máscaras, recortes y fondos definidos por el sistema operativo.
- No intercambiar ambos tipos de archivo: responden a contextos técnicos distintos.

## Regla de versión

No mezclar activos v1.0, v1.1, v1.2, v1.3 o KQ-DIGITAL-2.0 con esta entrega. El identificador canónico para implementación es `KQ-DIGITAL-2.1`.
