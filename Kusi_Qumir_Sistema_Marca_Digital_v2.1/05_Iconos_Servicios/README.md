# Iconos de servicios

Set digital aprobado para vuelos, hoteles, tours, cruceros y asistencia.

- Mantener el trazo y la geometría originales.
- Usar `#0F172A` como estructura y `#00ABAA` como acento.
- No recolorear con `#9BBFE6` cuando el icono comunique una acción crítica sobre fondo blanco: su contraste es insuficiente.
- Acompañar el icono con una etiqueta cuando afecte una decisión de compra o reserva.
- Tamaño visual recomendado: 24 px o más; el área interactiva debe ser de 44 × 44 px como estándar interno.
